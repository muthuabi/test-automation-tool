🚨 TROUBLESHOOTING

No logs in terminal?
  1. Verify backend is running: ps aux | grep node
  2. Run verification: bash verify-logging.sh
  3. Check for errors in backend terminal

Worker errors?
  1. Run: bash verify-logging.sh
  2. Reinstall: cd backend && npm install
  3. Check node_modules exists

Settings validation error?
  1. Clear browser cache: Ctrl+Shift+R
  2. Reload page
